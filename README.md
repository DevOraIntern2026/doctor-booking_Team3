# Doctor Booking

Doctor Booking is a web and mobile platform for discovering doctors, viewing availability, booking appointments, and managing appointments.

The platform also provides AI-assisted doctor recommendations based on the patient's needs.

##  Technologies

- Backend: Node.js
- Web: Next.js
- Mobile: Flutter
- UI/UX: Figma
- AI: Doctor Recommendation
- Testing: QA
